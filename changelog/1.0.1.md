# ✨ DreamHud v1.0.1 — Minor Cleanup Update

> *Released on*: November 2025  
> *Codename*: **"Silent Layer"** 🌌

---

## 🌙 Overview

This update focuses on **codebase cleanup** and **API stability improvements**.  
All debugging remnants and unused administrative commands have been removed to streamline production usage and prepare for the upcoming **v1.1.0** feature update.

DreamHud continues to provide a flexible HUD rendering system for developers seeking to create layered, animated, and highly customizable interfaces inside Minecraft.

---

## 🛠️ Changes

### 🔧 Internal Improvements
- Removed redundant warning logs:
  ```java
  this.plugin.getLogger().warning(String.format("Background introuvable : %s", name));
  ```
  → These have been silently ignored instead, preventing unnecessary console noise when backgrounds are missing.

- Removed legacy developer test commands:
    - `/test1`
    - `/test2`

### 🧩 General Enhancements
- Slight internal refactoring to improve background loading consistency.
- Reduced log verbosity in production environments.
- Ensured all example modules remain functional and unaffected by removals.

---

## 🧠 Developer Notes

This version does **not** introduce API changes — all interfaces remain stable and backward-compatible with v1.0.0.

If you used DreamHud in custom plugins, no migration or rebuild is required.  
You can safely upgrade to v1.0.1 by replacing the JAR file.
